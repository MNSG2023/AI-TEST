# AI-TEST

A tiny public repo to test ChatGPT↔GitHub workflows.

## What this repo is for
- Verifying that ChatGPT can read, branch, commit, and open PRs.
- Trying out automation patterns (scaffolds, CODEOWNERS, CI stubs).

## Branch strategy
- `main`: stable.
- feature branches: short-lived, PRs into `main`.
